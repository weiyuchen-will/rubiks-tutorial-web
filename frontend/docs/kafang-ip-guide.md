# 咔方 IP 动态五官与语音包

## 动态五官

- 默认状态：自动眨眼，瞳孔轻微左右看，身体轻微弹动。
- 说话状态：点击助手卡右侧播放按钮后，嘴巴进入开合动画，台词切换为语音包内容。
- 开心状态：星星眼、张嘴笑、跳起来，适合完成还原、胜利、连续正确。
- 紧张状态：眉毛上挑、嘴巴收紧、身体抖动、冒汗，适合计时中、错题、失败。
- 冲刺状态：身体前倾、嘴巴更夸张，适合开始学习、对战、下一关。

## 语音包分类

- guide：通用引导，用于首页和关于页。
- lesson：教程、课程播放、学习路线、公式训练。
- practice：练习、成绩详情、专项训练、成绩记录。
- battle：对战、对战房间。
- shop：金币商城。
- profile：我的页面。
- settings：设置、主题、语言、音乐。
- cheer：排行榜、玩家主页、鼓励反馈。

## 后续替换真实音频

当前语音包使用本地 mock 台词和 H5 系统朗读能力。若要换成真实语音文件，可按分类放入 `static/voices/kafang/`，并在 `common/kafangVoice.js` 中给每条台词补充音频地址。
